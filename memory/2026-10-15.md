# 2026-10-15 — Audit & Hardening Firewall WIN01-SERVERTDI

## Ringkasan Hari Ini
Pak Bos minta review keamanan server WIN01-SERVERTDI (Windows Server 2025, Primary Domain Controller AD `TDI.Twink.co.id`, HPE ProLiant DL20 Gen10 Plus). Selesai audit + hardening Prioritas 1 (pembatasan firewall RDP/SQL/WinRM).

## Hasil Audit Awal
- **1 KRITIS:** SQL Server (1433) terbuka `0.0.0.0`
- **4 TINGGI:** RDP 3389/3387 terbuka; firewall default "NotConfigured"; BitLocker tidak terpasang; banyak port AD terbuka (88/135/389/445/5985/9389)
- **2 SEDANG:** update Windows manual; RAM hampir penuh (4/32 GB tersisa)
- **1 INFO:** port aplikasi custom (6333, 22350-52, 3050, 5504, 3387) belum dipetakan
- **4 BAIK:** VBS/WDAC aktif; tanpa IP publik; gateway OpenClaw loopback; akses via Tailscale

## Yang Sudah Dikerjakan (Prioritas 1 — SELESAI)
Hardening firewall inbound untuk 3 service:

| Port | Service | Allow dari |
|------|---------|-----------|
| 1433 | SQL Server | `192.168.18.0/24` + loopback (LAN internal saja) |
| 3389 | RDP | `192.168.18.0/24` + `100.64.0.0/10` (Tailscale) + loopback |
| 5985 | WinRM | `192.168.18.0/24` + `100.64.0.0/10` + loopback |

Detail eksekusi:
1. Backup firewall → `firewall-backup-20261015-182121.wfw` (rollback siap pakai)
2. Buat 4 rule baru prefiks `TDI - *` (SQL/RDP TCP/RDP UDP/WinRM)
3. Disable 6 rule lama `RemoteAddr=Any` (tidak dihapus, mudah rollback)
4. Verifikasi: tidak ada lagi rule `Any` aktif untuk 3389/1433/5985
